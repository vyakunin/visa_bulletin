About This Directory

This directory lists employers who have filed H-1B Labor Condition Applications (LCA) and PERM (Permanent Employment Certification) applications with the U.S. Department of Labor.

What You Can Find
  • Sponsorship Activity: See how many H-1B and PERM applications each employer has filed
  • Employer Profiles: View detailed statistics, salary data, and trends for each employer
  • Compare Employers: Filter by state and visa program to find relevant sponsors
