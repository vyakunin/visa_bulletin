# Salary Database Views & Pages - Comprehensive Proposals

## Executive Summary

This document proposes a comprehensive set of views and pages for the PERM/LCA salary database, designed to maximize user value, SEO traffic, and viral potential. Each view serves specific user needs while supporting the project's goals of transparency, employer accountability, and informed career decisions.

**Key Design Principles:**
- **Multi-perspective access** - Same data, different angles (employer, job title, location, country)
- **Comparison-driven** - Enable users to compare and benchmark
- **Trend analysis** - Show historical patterns and predictions
- **Actionable insights** - Help users make decisions, not just view data
- **SEO-optimized** - Each view generates thousands of long-tail pages
- **Viral potential** - Shareable insights and controversial revelations

---

## 4. Country of Origin Views

> **⚠️ DATA AVAILABILITY NOTE:**  
> **PERM data contains `COUNTRY_OF_CITIZENSHIP` and `FOREIGN_WORKER_BIRTH_COUNTRY` fields** (verified in source files with sample data like 'POLAND', 'INDIA'), BUT:
> - We're **not currently importing/storing** these fields in our database
> - **H-1B/LCA data does NOT have** country of origin fields (privacy by design)
> - **Implementation requirement:** Add country fields to database schema (`models/salary.py`) and importer (`lib/parsing/salary/db_importer.py`) before country views are possible
